# Gespeicherte Teshuvot

Nach bestätigter Einreichung im Frageeditor erzeugt **Save Teshuva** hier ein HTML/JSON-Paar:

`teshuva-<Issue-Nummer>-<Anfrage-Hash>.html` und `.json`.

Die JSON-Datei enthält die Frage, das gewählte Profil aus `Rav`, die verwendeten Originalquellen und gegebenenfalls den optionalen OpenAI-Entwurf. Beim erneuten Versuch wird dieselbe Antwort wiederverwendet. Eine geänderte Frage bekommt eine neue Datei.

Die Website zeigt diese Antworten nach erfolgreicher Veröffentlichung auf `teshuva.html`. Alte Platzhalter werden nicht als neue Teshuvot veröffentlicht.

Anleitung: [docs/TESHUVA_DE.md](../docs/TESHUVA_DE.md).
